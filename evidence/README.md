# Evidence

This directory holds what backs the claims in the [README](../README.md) and [VERIFICATION.md](../VERIFICATION.md). It
holds two different kinds of material, and they should not be confused.

- **Evidence:** raw measurements, the scripts that turn them into the published figures, and a description of the
  method. You can rerun the scripts and get the same numbers, and you can judge the method yourself.
- **Review statements:** what an AI agent reported after reviewing or testing a build ("I verified …", verdicts,
  delivery messages). These record what was claimed and by whom. They are not proof on their own.

## What is in each release directory

| directory | kind | contents |
|---|---|---|
| `monerodato.0` … `monerodato.7` | mostly review statements | Agent verdicts and delivery messages, with a few raw outputs. Kept as they were published. |

| `gate-design` | design notes | Notes on the consensus gate tests. |

## Methods

- [methods/timing-kit.md](methods/timing-kit.md): resyncs of a fixed block range on the Core 2 Quad and Pentium G6950
  test boxes, arms alternated (B N N B). It backs the .9 CPU and wall-time claims on those boxes.
- [monerodato.9/METHODS.md](monerodato.9/METHODS.md): the optimizer's scoring, the HDD VM kits, the fast-box replays and the
  per-commit isolation runs (each commit alone on stock, A C C A).

## How to rerun the figures

All scoring scripts use the Python standard library only. Run them from `evidence/monerodato.9/` with `python3`.

- **Front-page figures:** [monerodato.9/README.md](monerodato.9/README.md) lists one command for each published
  figure.
- **Commit table:** [monerodato.9/data/per-commit/README.md](monerodato.9/data/per-commit/README.md) maps each cell
  to the command that prints it.
- **Timing-kit tables:** the README in each `data/perf/<box>_dot9*/` directory gives its table and the files it is
  computed from.
- **Whole syncs on low-spec machines** (the README's "On real low-spec machines" rows for the Atom and the G6950):
  [monerodato.9/data/sync/README.md](monerodato.9/data/sync/README.md) gives the rules and the command.

The timing data are gzipped CSVs with a header row. `height` is always the true block height: monerod's log line
`Height: N` is for block N-1.

## What has not been checked

- **Correctness:** the timing kits only show that each run ended on the same chain as a reference node, with no
  verification-failure lines. That a build verifies blocks correctly rests on the differential tests and the consensus
  gate tests, not on the timing data.
- **Scope:** all measurements are on the FCMP++ stressnet (testnet), not on mainnet.
- **Machines:** each figure comes from one machine class and a few runs a side. A difference smaller than the
  run-to-run spread on that machine is reported as no difference. Other hardware may differ.
- **Independence:** no one outside the project has reproduced these numbers yet. The data and scripts are here so that
  someone can.
- **Audit:** the code has had no security audit.
