## Notes
- **Hashes:** every fastbox and warm-up run ended with the reference node's hash (the `hash_match` / `tip … yes` columns), and every replay run with the expected hash at 3,103,500 (`HASH_OK` in `run.log`).
- **The warm-up's `errors 2`** in `summary.txt` is a false match: `grep -c ERROR` also counts the two log-category banner lines, which contain the word. `error_level_counts.txt` counts ERROR-level lines, and every run has 0.
- **Not included:**
  - the nodes' full logs (they hold peer addresses);
  - the chain-database snapshots (15-19 GB each; they are the public stressnet chain at the named heights);
  - the binaries, which `recipe/pc_build.sh` rebuilds from the arm branches.
- **The HDD VM's node logs** are not included either (they hold peer addresses), except in `hddvm-stock-base/`, where the peer address is replaced by `<peer>`. Their warm-up lines are in `warmup-hddvm/warmup_lines.txt`.
