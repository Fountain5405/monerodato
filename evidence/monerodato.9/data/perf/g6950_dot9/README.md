**Run 6's peak RssAnon** came early, 9 minutes in. At the pass it was 651 MiB.

**Top-block hash:**
- **Runs 1, 3 and 4:** the driver's own check got no answer (`get_info` timed out on a busy node), so the log reads `top block -1 ... match=NO`. That is a missing reading, not a mismatch.
