# The whole .9 against stock on a slow disk (HDD VM), with and without `--db-cache-drop`

**What this measures:** monerodato.9 as released, against the stock reference build, syncing on a slow disk. .9 is tried two ways:
- as a user starts it, without options;
- with `--db-cache-drop`, the opt-in LMDB page cache drop and pruning prefetch.

Each is measured without a memory cap and under a 1,536 MB cap.

- **What the option does on .9:**
