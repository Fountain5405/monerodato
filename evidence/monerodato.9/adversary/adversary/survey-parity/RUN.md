# How to run the survey tests

One row per class: the tree each test family applies to, the build, the
exact command, what to expect, and which log in `results/` it
reproduces. Test logic is unchanged from what produced those logs; only
names moved when the gate tests were adopted.

**Trees.** The logs in `results/` were produced on the .7-era and
BP+ split prototype internal trees; the adopted forms of those same
tests are in the public repository and ship with the .9 tag. For every
class below, the public .9 tree (the release the tag points at, i.e.
`22c1f9ee7` plus the adopted gate-test commits) can reproduce the run.

**Build (all classes).** Standard build with tests enabled; then build
the targets:

    cmake -B build ... && cmake --build build --target unit_tests core_tests

Run times are from a 12-core desktop machine, single suite at a time.

## C1 / C4 — BP+ permutations, positions, batch splits (gtest)

Adopted, public with the .9 tag: `tests/unit_tests/rct_batch_gates.cpp`
