# Counterfeiting-survey parity program

Every class of flaw in the 2026 counterfeiting survey (Rucknium's gist, "2026 Counterfeiting vulnerabilities in cryptocurrency
privacy projects", https://gist.github.com/Rucknium/a38821f8a1e0e0a115c0f4bc72d3bdb1,
and the project cases behind it) was turned into executed adversarial tests against this
fork, on both code lines that existed when the program ran and — for the
classes the adopted gate tests cover — on the final release line.

Reviewer: adversary (second reviewer). Program ran 2026-11-13; the .9
reruns noted below ran 2026-11-19. Evidence: this folder (raw logs in
`results/`, standalone test code in `tests/`), the differential-corpus
data and tools in `../../data/` and `../../tools/`, and the test commits
listed below the table.

## Method

- Two offline oracles: stock monero and the fork candidate, each fed the
  same inputs; verdicts compared, and both compared against recorded
  labels. Oracle chain states: H1 (height 3,105,421; top block 3,105,420
  `d7fd69a2043314793b46616c09939eae85d1551eb29881b87615ea74b99eb866`)
  and H2 (height 3,106,401; top block 3,106,400
  `0d7739d8fb7f77bb22feed1c5734f8ac204c7aab668ad873146436b801e15adc`).
- Case sets: accepted parents (regression floor), byte-flip mutants of
  those parents, and 396 structured mutants over eight shapes
  (value-preserving non-canonical varints, junk framing, duplicate
  inputs, copied/swapped key images, amount+1, and the statement-level
  shapes below). Seeds fixed; case ids deterministic
  (`../../tools/mutant_gen.py`, `../../tools/corpus_generator.py`).
- Whole-block tests run under the repository's own chaingen replay, on
  mined-style blocks whose transactions the pool has either seen (and
  refused or stored) or never seen, and — through the
  `supplemented_block` event — blocks delivered as bytes with their
  transaction blobs on the sync route.
