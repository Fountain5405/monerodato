  1. apply `patches/0001-0003` to dalek-ff-group 0.5.0 from crates.io. 0001 adds a radix-2^51 backend, which was rejected for monerod; 0002 adds the saturated 4x64 backend that s64 uses; 0003 changes s64's `wide_reduce` and `random`;

  4. build natively (Ninja, Release, `ARCH=native`). If a build directory already exists, first delete `libfcmp_pp_rust.a` and the generated `fcmp++.h` in it, because cmake's cargo step does not notice a changed `[patch]` crate.
