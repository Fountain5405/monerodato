## Replay
- **One run** (`bpp_run*.sh <name> <monerod>`, `END=3103500`):
  - before each run, the chain restores the database at height 3,103,300 (`stressnet_h3103300c`, sha256-checked) from the control box;
  - the run drops the page cache, then starts the test node with `--show-time-stats 1`, peering only with the source node;
  - sample height and the node's CPU every second until block 3,103,500;
  - check the top block's hash against the source's;
  - write `run.log`, ending `BPP_RUN_DONE end` and `HASH_OK`.
- **The metric** is wall time between the node's time-stats lines for blocks 3,103,320 and 3,103,500, and node CPU over the same span.

## Fastbox
- **One window** (`fb_window.sh <out> <END> <TIMEOUT> <ROUNDS> "S|<monerod>|<flags>" "E|<monerod>|<flags>"`):
  - each round copies the window's snapshot into the scratch data directory;
  - it starts each arm in turn, syncs from one peer to `END`, and records wall time, CPU and RssAnon (2 s), plus anon memory after 45 s idle;
  - it checks the top block's hash.
- **The windows:**
  - heavy: 3,105,401-3,105,444, `--block-sync-size 5`;
  - small-tx: 3,106,401-3,106,800.
